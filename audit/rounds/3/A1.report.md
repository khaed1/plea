## Findings

### 1. Medium: 24h trend band reads 'no history' (+5) after the first day whenever hour H-24 had no trade: the 25-slot ring's only older reference sits in the current hour's slot, so a dust trade (or any trade this

`src/CabalGate.sol:280`

```
        uint256 ago = h.price24hAgo();
        if (ago == 0) score += 5;
        else if (latest > ago * 102 / 100) score += 9;
        else if (latest * 100 >= ago * 98) score += 5;
```

THREAT-MODEL invariant 3 says the 24h trend band (up 9, flat or no history 5, down 0) is computed from the hook's hourly checkpoints; README line 118 reserves 'no history' for a market without a day-old checkpoint. CabalGate._factScoreAt (src/CabalGate.sol:280-283) reads PleaHook.price24hAgo() (src/PleaHook.sol:285-298), which looks in a 25-slot ring keyed by hour % 25 for the checkpoint of hour H-24, else for the newest checkpoint with hour <= H-24, else returns 0. The slot of hour H-25 is the slot of the current hour H, and every other slot holds hours H-23..H-1 in an active market. So whenever hour H-24 itself had no trade (a quiet hour; common at night for a meme token), the first trade of hour H overwrites the only surviving reference older than 24 hours (PleaHook._checkpoint, src/PleaHook.sol:1004-1014) and price24hAgo() returns 0 for the rest of that hour: the gate scores 'no history' (+5) although the market has a full day of hourly checkpoints. The same happens with no trade in hour H at all when the slot of H-25 was never written or was rotated past (specialist proof TrendGap: 23 consecutive hourly checkpoints, price24hAgo() == 0, factScore 26 instead of 30). Who gains: a seller in a market that fell more than 2% over the day (true band 0) picks an hour whose H-24 was quiet, makes a dust buy as the hour's first trade (or simply pleads after anyone else traded this hour) and is scored 5 instead of 0, i.e. the need falls by 5 at the cost of one tiny buy with no price move. It is cheaper than R2-A1-1 (which needs a >2% pump held across a boundary for 4 points) and is not described anywhere. The mirror effect hits honest sellers in a rising market (9 becomes 5). Bounded to the trend band (5 points), no funds at risk: Medium (wrong fact score, cheaper for the attacker than the points are worth). The defect lives in the hook's read (area A3) but it is the gate's fact score and invariant 3 that are wrong; both round-3 A1 specialists (permissions: Low, economics: Medium) reported the two triggering mechanisms; they are merged here. Fix (hook side, read only, no agreed number changes; the gate has 83 bytes of room and needs none): once the pool is older than a day, let price24hAgo() fall back to the oldest checkpoint the ring still holds when no checkpoint at or before H-24 exists, or widen the ring to 26 slots so the current hour never evicts the H-25 reference; either way the test below passes and a market younger than a day still reads 'no history'.

Before any trade in hour H: hook.price24hAgo() == the A+1 checkpoint (462796487183101408589196, nonzero) and gate.factScore(bob, bal/10) == 35 (share 16 + hold 2 + gain 8 + up 9). Then alice buys 1 IMD in hour H (the hour's first trade writes ring[H % 25], the slot of hour A+1 = H-25). Expected: price24hAgo() still the A+1 checkpoint and factScore 35. Actual on this code: price24hAgo() == 0 and factScore 31 (trend 'no history' 5). The test fails with 'the same price history must give the same trend band: 31 != 35'.
```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.26;

import {Fixture} from "../utils/Fixture.sol";

/// @dev The gate's 24h trend band reads `PleaHook.price24hAgo()`, which searches a 25-slot ring keyed
/// by `hour % 25`. The checkpoint of hour H-25 shares its slot with hour H, so the first trade of the
/// current hour evicts the only reference older than 24 hours whenever hour H-24 itself had no
/// trade. The gate then scores "no history" (5) instead of the real trend (up 9 / down 0).
contract TrendEvictionTest is Fixture {
    function test_aTradeInTheCurrentHourErasesTheDayOldReference() public {
        vm.warp((vm.getBlockTimestamp() / 1 hours + 1) * 1 hours + 1);
        buy(bob, 50e18); // hour A: bob's position, checkpoint A
        skip(1 hours);
        buy(alice, 1e18); // hour A+1: checkpoint A+1 (pre-pump price)
        skip(1 hours); // hour A+2 == H-24
        uint256 snap = vm.snapshotState();

        // Control: hour H-24 has a trade, so the ring holds the reference directly.
        buy(alice, 1e18);
        skip(1 hours);
        buy(alice, 400e18); // hour A+3: the pump; every later checkpoint sits above the A+2 reference
        for (uint256 h = 4; h < 26; ++h) {
            skip(1 hours);
            buy(alice, 1e18);
        }
        skip(1 hours); // hour H = A+26, no trade yet this hour
        uint256 ago1 = hook.price24hAgo();
        uint8 f1 = gate.factScore(bob, plea.balanceOf(bob) / 10);
        (uint256 spent1, uint256 held1,) = hook.basisOf(bob);
        emit log_named_uint("control ago", ago1);
        emit log_named_uint("control latest", hook.latestPrice());
        emit log_named_uint("control fact", f1);
        emit log_named_uint("control spent", spent1);
        emit log_named_uint("control held", held1);

        // Same market, but hour H-24 is quiet and the current hour has one dust trade.
        vm.revertToState(snap);
        skip(1 hours);
        buy(alice, 400e18); // hour A+3: the same pump
        for (uint256 h = 4; h < 26; ++h) {
            skip(1 hours);
            buy(alice, 1e18);
        }
        skip(1 hours); // hour H
        uint256 agoBefore = hook.price24hAgo(); // the A+1 checkpoint still answers
        buy(alice, 1e18); // the hour's first trade: writes slot H % 25 == (H-25) % 25, evicting A+1
        uint256 ago2 = hook.price24hAgo();
        uint8 f2 = gate.factScore(bob, plea.balanceOf(bob) / 10);
        emit log_named_uint("evicted ago before dust trade", agoBefore);
        emit log_named_uint("evicted ago after dust trade", ago2);
        emit log_named_uint("evicted latest", hook.latestPrice());
        emit log_named_uint("evicted fact", f2);

        assertGt(agoBefore, 0, "a day-old reference existed before the hour's first trade");
        assertEq(ago2, 0, "the hour's first trade evicts the only reference older than 24h");
        assertEq(f2, f1, "the same price history must give the same trend band");
    }
}
```
